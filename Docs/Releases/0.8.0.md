# ADA 0.8.0

The first public release of **ADA: Automated Deployment Assistant**, a cross-platform mod manager for Satisfactory.
It's a preview: most of ADA is in place, but parts of it have only been tested on one machine. That's where you
come in.

## We're looking for testers

ADA has been developed and tested mainly on **macOS**. The other platforms are covered by automated tests, but
haven't been used in real play. We'd especially like to hear
from you if you play on:

- **Windows**, with Steam or the Epic Games Launcher;
- **Linux**, with Steam (native, Flatpak or Snap) and Proton, or Epic through Heroic or Legendary, including the
  Steam Deck;
- **a dedicated server**, connected over SFTP, FTP with TLS, or a shared folder.

**Dedicated server support is untested.** It has never been used against a real server. Back up your server's
saves and mods before letting ADA change them, and expect rough edges.

Whether things went well or badly, please tell us in the
[issue tracker](https://github.com/StillAccursed/ADA/issues). Include your operating system, launcher (or server
host and connection type), what you did and what happened. The **Activity → Logs** tab shows ADA's logs; check
them for anything personal before attaching them.

## What's in it

- **Mods.** Browse and search the [ficsit.app](https://ficsit.app) catalogue, filter by tags and keep favourites.
  Install, update, remove or pick a specific version, one at a time or queued together. Dependencies and
  compatible versions are worked out for the selected game.
- **Recovery.** Interrupted mod changes are recovered, and damaged or missing mod files are found and repaired
  where possible.
- **Dashboard.** Your installations, recently updated mods, disk usage and profiles at a glance.
- **Profiles.** One set of mods per playthrough, switched in one step. Satisfactory Mod Manager profiles
  (`.smmprofile`) can be imported.
- **Saves.** Browse sessions and saves, see which mods a save was made with, and switch to exactly those mods.
  Copy, export and import blueprints between sessions.
- **Backups.** Back up saves, blueprints, game and mod settings, and ADA's own settings, by hand or on a schedule.
  Restore any part; every restore can be undone.
- **Dedicated servers** *(untested)*. Manage a server's mods over SFTP, FTP with TLS, or a shared folder, and push
  mod settings to it.
- **Activity.** A history of everything ADA changed, with failures and their reasons, plus ADA's logs.

## Installing

Download the package for your platform below. No separate .NET install is needed.

| Platform | Download |
|---|---|
| Windows | `StillAccursed.ADA-win-x64-Setup.exe` (ARM: `win-arm64`) |
| macOS | `StillAccursed.ADA-osx-arm64.dmg` (Intel: `osx-x64`) |
| Linux | `StillAccursed.ADA-linux-x64.AppImage` (ARM: `linux-arm64`) |

Ignore the `.nupkg` and `.json` files; they're for ADA's updater.
[Installation](https://github.com/StillAccursed/ADA/blob/main/Docs/Installation.md) has the details for each
platform.

## Known limitations

- **Builds aren't code-signed.** Windows SmartScreen and macOS Gatekeeper warn the first time ADA runs. On macOS,
  ADA also asks again for its keychain entries after each update. Installation explains how to get past both.
- **ADA doesn't update itself yet.** Install new versions from the Releases page; your settings and data are kept.
- **Only launcher-managed games are found.** Choosing a game folder by hand isn't available yet.

Close Satisfactory before changing its mods. Even an efficient factory benefits from stopping the machinery before
replacing parts.
